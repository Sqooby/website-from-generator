# Status projektu - 2026-02-17

## Stack techniczny

- **Next.js 16** + React 19 + TypeScript
- **Tailwind CSS v4** (CSS-based config, bez tailwind.config.js)
- **Prisma 7** + SQLite (dev) / PostgreSQL (produkcja)
- **NextAuth.js v5** - JWT session, Credentials + Google OAuth
- **bcryptjs** - hashowanie hasel
- **Cloudflare Pages** - deployment (next-on-pages)

---

## Architektura (SOLID)

```
src/
├── app/                          # Routing HTTP - tylko orchestracja
│   ├── api/
│   │   ├── auth/
│   │   │   ├── [...nextauth]/    # NextAuth handler
│   │   │   └── register/        # POST rejestracja
│   │   ├── websites/             # GET, POST (auth required)
│   │   │   └── [id]/            # GET, PATCH, DELETE (auth + ownership)
│   │   ├── rsvp/                 # POST (publiczny, CORS)
│   │   └── deploy/               # POST deployment
│   ├── (public)/                 # Marketing + auth pages
│   │   ├── page.tsx              # Homepage
│   │   ├── templates/            # Galeria szablonow
│   │   ├── pricing/              # Cennik
│   │   ├── builder/              # Kreator stron
│   │   ├── login/                # Strona logowania
│   │   └── register/             # Strona rejestracji
│   ├── (dashboard)/              # Panel uzytkownika (chroniony)
│   │   └── dashboard/
│   │       ├── layout.tsx        # Sesja + logout (Server Action)
│   │       └── page.tsx          # Lista stron (TODO: mock -> API)

├── server/                       # Backend - warstwy
│   ├── repositories/             # Tylko Prisma, zero logiki
│   │   ├── website.repository.ts
│   │   ├── rsvp.repository.ts
│   │   └── user.repository.ts
│   ├── services/                 # Logika biznesowa

├── components/
│   ├── ui/                       # Prymitywy (Button, Input, Select...)
│   ├── layouts/                  # Header, Footer
│   └── features/

│       └── auth/                 # LoginForm, RegisterForm

├── templates/                    # System szablonow weselnych
│   ├── base/sections/            # Hero, Countdown, Story, Events, RSVP, Gallery...
│   ├── classic-elegance/
```
